# Active Directory User Management

## 1. Project Overview

This exercise demonstrates basic user administration using Active Directory Users and Computers (ADUC) on Windows Server 2022.

## 2. Lab Environment

- Operating System: Windows Server 2022
- Virtualization: VMware
- Directory Service: Active Directory Domain Services
- Management Tool: Active Directory Users and Computers

## 3. Practical Tasks Performed

### Task 1: Organizational Unit Creation

Created an Organizational Unit named `IT-Department` to organize and manage IT department user accounts.

### Task 2: User Account Creation

Created a test user account inside the `IT-Department` Organizational Unit.

Steps performed:

1. Opened Server Manager.
2. Navigated to Tools.
3. Opened Active Directory Users and Computers.
4. Expanded the domain.
5. Right-clicked the IT-Department OU.
6. Selected New → User.
7. Entered the test user's details.
8. Configured the account and completed creation.
