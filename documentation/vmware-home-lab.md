# VMware Home Lab – IT Infrastructure Practice

## 1. Project Overview

This project documents my VMware-based home lab created to practice Windows Server administration, Active Directory, networking and IT Support troubleshooting.

The purpose of this lab is to gain practical experience with virtual machines and common enterprise IT infrastructure technologies.

## 2. Virtualization Platform

| Component | Details |
|---|---|
| Virtualization Software | VMware Workstation |
| Server Operating System | Windows Server 2022 |

| Network Services | DNS and DHCP, where configured |

## 3. Home Lab Architecture

The home lab consists of virtual machines running on a physical computer using VMware Workstation.

Purpose:

- Group Policy management

### Virtual Machine 2 – Windows 10/11 Client

Purpose:

- Windows desktop administration

- Domain user authentication
- Group Policy testing
- Windows troubleshooting
- Network connectivity testing

## 4. VMware Networking

VMware provides different virtual networking modes.

### Bridged Networking

Connects the virtual machine to the physical network through the host network adapter.

### NAT Networking

Allows virtual machines to access external networks through the host's network connection.

### Host-Only Networking

Provides an isolated virtual network for communication between the host and virtual machines.

The network mode is selected according to the lab requirements.
